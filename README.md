# Mata Kilat: Jurus Skimming dan Scanning

Gim edukasi Bahasa Indonesia tentang teknik membaca cepat. Bersama Tasi si tarsius, murid menguasai Jurus Sekilas (*skimming*) untuk menangkap isi umum bacaan dan Jurus Pindai (*scanning*) untuk menemukan informasi tertentu dengan cepat dan tepat.
